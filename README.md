# Electron Configuration Lab

A practice tool for general chemistry students. Given an atom or ion (H–Kr, main-group ions, and transition-metal cations), students:

1. Count the electrons.
2. Write the electron configuration (full or noble-gas core notation).
3. Fill in an orbital box diagram using the Aufbau principle, Hund's rule and the Pauli principle.
4. Decide whether the species is diamagnetic or paramagnetic, and count unpaired electrons.

**Coaching** mode checks each step and explains which rule was broken. **Testing** mode gives no feedback until the end, then shows a score and a summary that can be printed or saved as a PDF for Blackboard.

Everything is in one self-contained page, `index.html`. No install is needed; open the GitHub Pages link.

Notes on the answer keys:
- Cr and Cu use their actual configurations ([Ar]4s¹3d⁵ and [Ar]4s¹3d¹⁰).
- Transition-metal cations lose 4s electrons before 3d (Fe²⁺ = [Ar]3d⁶).
